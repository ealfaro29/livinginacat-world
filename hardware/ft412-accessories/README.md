# Alfonsito · Piezas y placas / Parts and plates

Estas piezas complementan la [entrega mecánica V1](../ft412/PUBLIC-RELEASE.md). Las unidades son milímetros. Los archivos STL describen piezas imprimibles, los STEP conservan sólidos editables y los 3MF conservan la disposición. Las cinco placas iniciales en `01-placas-originales/` contienen geometría. Las demás placas de Bambu también conservan sus ajustes de laminado. Abrí el proyecto en Bambu Studio, elegí la impresora y el material que realmente usarás y revisá la vista laminada antes de enviar a tu máquina.

These designs supplement the [V1 hardware release](../ft412/PUBLIC-RELEASE.md). Units are millimetres. STL files are printable shapes, STEP holds editable solids, and 3MF projects preserve their plate layouts. The five initial files in `01-placas-originales/` contain geometry. The other Bambu projects also retain their slicing settings. Open the project in Bambu Studio, select your installed printer and material, and check the slice preview before sending.

Para regenerar piezas que declaran dependencias en su cabecera, usá `uv run ruta/generar.py`. Los generadores de los soportes también exportan los sólidos impresos sin necesitar el CAD comercial del perfil. Para el organizador, ejecutá `uv run --no-project --with numpy --with trimesh --with manifold3d --with matplotlib --with scipy python organizador/generar_bento.py` desde esta carpeta. Algunos modelos conservan las comparaciones opcionales con referencias dimensionales del proveedor si las tenés localmente.

For scripts with inline dependency declarations, run `uv run path/to/generar.py`. The mount generators can export the printed geometry without the supplier extrusion model. The organizer command above regenerates the six STL files. Optional fit comparisons can use locally supplied commercial references. Historical material names describe the saved projects. The operator’s current print choice belongs to the individual run.
