# Living in a Cat World

Start with [project continuity](docs/CONTINUITY.md). It maps the website, Alfonsito V1, the printed V2 design and Entity software to their source directories, verification commands and outstanding physical checks. The operator interface and project guides have Spanish and English versions. Use the conversation’s language in chat.

Use the root Node project for the public site and `software/entity/` for the robot software. Its local preview and automated tests work without moving hardware. The physical rig uses a saved calibration and a manually established origin. Check live status before running work on it.

See [contribution and publication instructions](CONTRIBUTING.md) and [Entity’s development instructions](software/entity/AGENTS.md). Machine profiles, credentials, personal records and phone captures belong in private storage.
